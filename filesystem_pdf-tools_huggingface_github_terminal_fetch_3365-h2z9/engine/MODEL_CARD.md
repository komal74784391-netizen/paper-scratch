# Polygraph Harmonizer v3

Polygraph Harmonizer v3 is an instruction-tuned synthesis engine used to compile
structured crosswalks from reference registers and source filings. It reads a
register, extracts candidate criteria and emits normalised crosswalk rows for
downstream review.
