# Conformance Crosswalk 2025 - release workspace

This workspace area holds the working material for the 2025 conformance crosswalk
release. The release maps the technical bulletins filed by member organisations
during the autumn consultation onto the criteria of the Conformance Criteria
Register 2025.

Contents:

- `crosscheck_requests.csv` - analyst request sheet; register identifier and
  scope text columns are still blank.
- `reference_index.csv` - quick-reference index of the register prepared for
  desk use.
- `LICENSING_POLICY.md` - release licensing policy (RLP-4).
- `deliverables/` - published artefacts of the release.

Files in this workspace area are the working copies used by the release team.
