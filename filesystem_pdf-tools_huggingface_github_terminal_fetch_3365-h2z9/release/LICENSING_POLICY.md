# Release licensing policy (RLP-4)

Every published release carries exactly one license, and that license is
recorded in the release decision file before publication.

## 1. Candidates

The candidate licenses for a release are:

- the license of each direct data source used to compile the release;
- the license of each synthesis model used to produce the release.

## 2. Selection

Where more than one candidate license is available, record the most permissive
of them. Any attribution obligation stated in the selected license is carried
forward into the release notices.

## 3. Recording

Record the selected identifier exactly as issued by the license steward. Do not
translate, abbreviate or otherwise rewrite the identifier.
